- Título (6 palabras): `Un [acento]solo paso[/acento], nunca una lista`

- Paso 1: `Elige tu hábito` — `Máximo 3 hábitos activos a la vez — nunca una lista larga.`

- Después: `Un solo paso cada día, y un "Reinicio Amigable" si faltaste unos días.`
